Sistema Confea/CREA-AM

Identidade técnica verificada. Não é banco de vagas.

O Pro‑Link conecta empresas a engenheiros pelo que eles já provaram fazer, com ARTs e CATs validadas pela API oficial do CREA-AM. Sem dado não verificado, sem ranking de pessoas.

Cada perfil é verificado pela API oficial do CREA-AM
Como funciona

Do registro à conexão, em três passos

O mesmo fluxo verificado atende os dois lados.

1

Identidade verificada

O profissional entra com o CPF e a plataforma importa ARTs e CATs direto da API do CREA-AM. O histórico já nasce comprovado.

2

Demanda por atividade

A empresa publica a demanda escolhendo as atividades técnicas (Tabela TOS). O motor cruza demanda e capacidade comprovada.

3

Interesse e contato

Os compatíveis aparecem por aderência. As partes manifestam interesse e conversam dentro da plataforma.

Tridimensionalidade

Três perspectivas. Uma dimensão a mais.

Confiabilidade e compatibilidade formam o plano. O contato verificado é a profundidade que faltava. A mesma lógica governa a segurança, onde o terceiro eixo é a perspectiva do Atacante.

Eixo X

Confiabilidade

Cada ART e CAT validada pela API oficial. Dado verificado, não apenas declarado.

Eixo Y

Compatibilidade

Aderência multidimensional entre demanda e perfil. Encaixe por dimensão, não ranking.

Eixo Z · profundidade

Contato

A ponte que faltava entre profissional e empresa, a dimensão que vira volume.

Dado verificado, não declarado

ARTs e CATs vêm da API oficial. O que aparece no perfil, o profissional provou.

Compatibilidade, não ranking

O engenheiro é encontrado pela aderência à demanda, nunca por uma nota de qualidade.

Auditável de ponta a ponta

Cada recomendação é reproduzível e registrada. Transparência para todos os lados.
