**Como consultar o banco.** Toda consulta SQL deste documento usa a mesma forma, e ela é a única do documento — o
`heredoc` existe para você não ter que escapar aspas dentro de aspas às 22h:

```
docker compose exec -T mariadb sh -c 'exec mariadb -uprolink -p"$MARIADB_PASSWORD" prolink' <<'SQL'
SELECT 1;
SQL
```

A senha nunca é digitada: `MARIADB_PASSWORD` é variável de ambiente do próprio container, posta pelo
`docker-compose.yml` (linha 38) a partir do `.env`. Dentro do heredoc, aspas simples são literais. O `-T` é
obrigatório: sem ele o `docker compose exec` aloca um TTY e o heredoc não chega ao cliente.
Se der `mariadb: not found`, troque `mariadb` por `mysql` nos dois lugares.

**Cole o bloco sem indentação.** O `SQL` de fechamento tem que ficar na coluna 1 da linha. Com um espaço na
frente, o shell não fecha o heredoc e o terminal fica pendurado esperando (saia com Ctrl+C e cole de novo).
Por isso os blocos de SQL deste documento estão todos encostados à esquerda, mesmo dentro de listas numeradas.
